7. Optional example — local model proxy

Optional, not needed to start. One test machine ran a local OpenAI-compatible proxy (for example LiteLLM on http://127.0.0.1:8000/v1) as a user service in front of the free NVIDIA models. The workspace does not install or require it. If you run one, keep its keys in the OS secret store (tools/secret.py), never in a file inside this folder.

8. AI Agent Client — Goose CLI

Install goose from its own releases page and put it on PATH. Example configuration (~/.config/goose/config.yaml; the key comes from the secret store):

provider: litellm
litellm_host: http://127.0.0.1:8000
litellm_api_key: <NVIDIA_API_KEY from your secret store>
litellm_model: nvidia/nemotron-ultra
Test: echo "hi" | goose run --text -

Goose reads AGENTS.md from the working directory automatically.

9. What Is Missing / Recommendations

  • OpenCode provider configuration: Gemini, NVIDIA, DeepSeek, Mistral providers are not yet configured in OpenCode. Use tools/setup_providers.py to add them with keys from KWallet.
  • Live DCOP test: Run SECRET_LIVE_TESTS=1 python3 -m unittest discover -s tools/tests -t . -v after opening the KWallet.
  • External audit: before a release, follow docs/procedures/release-audit.md; reports go to out/.
  • Git remote: No origin configured yet. Add remote and push when ready.
